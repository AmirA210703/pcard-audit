Ask a question about the P-card data

Type a question the way you would ask a colleague. The question goes to {% if nl_provider == 'gemini' %}Gemini{% elif nl_provider == 'anthropic' %}Claude{% else %}a language model{% endif %}, which writes a SQLite query against the transaction table. The server runs that query in read-only mode and shows you the answer and the query, so you can check the logic before you rely on it. Nothing here can change the data, and only the table definition and your question are sent to the model — no transaction data leaves this server.

How to use this dashboard

    
    
      
  1. Choose the year you are auditing. 2014 is the year under audit;
          earlier years are available for trend work.
    2. 
      
  2. Pick a prohibited category below. Click a single term to search just
          that word, or Search all terms to run every term in the category at
          once. Description terms go to the description search, vendor terms to the vendor
          search.
    3. 
      
  3. Or type your own keyword. The description search looks inside
          the merchant's line detail (for example gift card); the
          vendor search looks at the merchant name (for example postal).
          Matching is case-insensitive and partial, so liquor also finds
          PARKHILL'S WAREHOUSE LIQUOR.
    4. 
      
  4. Set a minimum amount to push small, low-risk charges out of the way.
    5. 
      
  5. Read the results — the month chart shows whether the hits cluster
          in one period, and any charge over the $5,000 single-transaction limit is marked.
          Sort any column by clicking its header.
    6. 
      
  6. Read the category note before you act. Every category has known false
          positives, and they are listed there.
    7. 
      
  7. Export to CSV to carry the population into your working papers.
    8. 
    

    

      A hit is a lead, not a finding. Descriptions are supplied by the merchant, are often just
      GENERAL PURCHASE, and cannot be relied on alone — obtain the receipt and
      the business purpose recorded in Works before concluding that a purchase was prohibited.
